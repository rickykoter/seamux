## Decision

a panel costs several times the tokens of one reviewer, so the person picks it where the extra check pays

## Consequences

one reviewer stays the default everywhere; a person turns the panel on per plan at planning time, per repo in .seamux/lookout.json, or per run in the Lookout tab; a session without the Workflow tool always runs one reviewer
