## Low

- **deep-plan.**
  - `deliver --base` is refused even when the recorded start sha is gone after a rebase (`deep_plan.mjs:388`).
  - The Bash write heuristic misses `git restore/switch/pull/add`, `perl -pi`, `prettier --write`, `curl -o`, `tar x` and `rsync` (`lib/state.mjs:462`).
  - Concurrent writes can lose an increment status change, for example a board click during `done` (`lib/state.mjs:105-145`, PLAUSIBLE).
  - `treeOf` writes blobs for large untracked files on every check.
- **Pages.**
  - deep-plan's Block and Attach depend on `window.prompt`/`confirm`, which an embedded WebView may not show.
  - The lookout comments hook tells the agent "Only the human resolves" even when `agentMayClose` is set (`lookout/hooks/comments.mjs:69`).
  - `/plan/` serves lookout pages with plan.js injected, and `__SLUG__` is filled with a filename.
- **crew.**
  - Uninstall wipes the sandbox registry, so reclaim later treats a running VM as never sandboxed.
  - `crew-sandbox prune` deletes live config dirs when `sbx ls` fails.
  - Uninstall prints success whatever happened, and kills `listen.pid` without checking what that pid now is.
  - `pkill -f crew-board-intent` also hits editors and test servers.
  - Apply strips the settings.json hooks without checking that the plugin is enabled.
  - settings.json writes aren't atomic.
  - `crew-backups/` grows without limit.
- **app.**
  - The review timeout kills only the direct child, and a pipe join can hang for good.
  - Quitting leaves review subprocesses running.
  - `move_native` can SIGTERM a reused pid.
  - Sessions in one workspace share one stop-hook payload file.
  - The port file isn't written atomically.
- **app UI.**
  - A failing tool whose output quotes the gate message raises a false gate band.
  - The review/sheet iframes cache the intent-server origin forever, with no catch.
  - In New workspace, ⌘↵ after "made but not yet listed" creates the workspace again.
  - The Wake column overflows below about 900px.
  - Timeline lane names truncate until siblings look identical (see `app-timeline.png`).
  - A double-click beats Wake's two-click publish confirm.
  - The `Desk` class in `desk.ts` is dead code (~680 lines).
- **board.**
  - "close plan" runs bare `node` from PATH.
  - The board's timestamp freezes while nothing changes.
  - The server exits on upgrade even when nothing will restart it.
- **restack / install.**
  - The printed push line uses a bare `--force-with-lease`, which never matches bash-guard's exception.
  - A local `base` branch is fetched but not updated.
  - The replaced app bundle is moved into `$TMPDIR`, which macOS purges.

## Checked and sound

- **Escaping.** HTML escaping holds in the board, lookout and deep-plan pages, and app/ui has no `innerHTML`.
- **Server.** The intent server checks Host, Origin and the token on POSTs.
- **App.** The Tauri capability is scoped to the main window, and `open_url` and the path commands validate their input.
- **Lifecycles and timers.** PTYs are reaped. seamux-mods polls once per process. crew's shell hooks are tiny and time-bounded.
- **Lookout comments.** 40 concurrent comment POSTs lost no threads.
- **Already-closed demo leads.** In the demo, ⌘M and `/` "not firing" and the narrow comment card were harness artifacts, not page bugs.
