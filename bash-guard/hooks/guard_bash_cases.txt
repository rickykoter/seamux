# Cases for guard_bash_probe.sh: one per line, `block <command>` or
# `allow <command>`. The command is written as the body of a JSON string, the
# way the hook payload carries it: \" is a quote, \\ a backslash, \n a newline,
# \t a tab. Blank lines and lines starting with # are skipped.
