# Security

Personal project, best-effort support. If you find a vulnerability — in the
intent server, the gate, the sandbox credential handling, or anywhere else —
please report it privately to **rickykoter@gmail.com** rather than opening a
public issue. You'll get a reply within a few days; fixes ship as ordinary
commits once you've had a chance to confirm them.

Before relying on any of the security-adjacent pieces, read the "Security
notes" section of the README — it states plainly what each one does and does
not protect against.
